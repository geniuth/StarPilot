# ID.4 미결 과제·판정 기록

작업하다 판정이 끝났거나 보류한 항목들. 잊어버리지 않기 위한 기록.

## 판정 완료 (더 파도 답이 안 바뀌는 것)

### 앞차 출발했는데 안 감(정차잠금에 갇힘) — 수정함 (2026-07)

실차 rlog(fc6a1528)로 확정. 앞차가 5m 앞에서 살살 기다 서면 플래너가 완전정지
(shouldStop)를 안 잡고 롱컨 상태가 "pid"에 머문다. 이 상태에서 차가 스스로 ESP
홀드(Motion_State==3)를 걸면, MEB의 `starting=(longControlState==starting)` 조건은
"stopping"을 안 거쳐 영영 False → `ACC_Anfahren`(출발요청)이 안 나가 잠금이 안 풀린다.
그래서 앞차가 출발해 openpilot이 가속을 2.5m/s²까지 명령해도 차는 홀드에 갇힌 채
안 움직이고, 결국 운전자가 밟아야 출발. 로그에서 ACC_Anfahren=0 내내 확인.

- if2도 MEB는 동일 구조(구멍 공유). HKG는 accel을 SCC에 직접 명령해 이 핸드셰이크가
  없어 해당 없음.
- 수정: carcontroller MEB `starting`에 "pid + esp_hold_confirmation + accel>0"를 OR로
  추가 → 정차잠금 중 가속 의지가 있으면 출발요청을 내보내 잠금 해제. 정상 정차
  (lcs=stopping 또는 accel≤0)에선 발동 안 함.

### 주행 중 기기 재부팅 → 시동 재점화까지 ACC 먹통 — 소프트웨어 해결 불가

메커니즘 (코드로 확정):
1. 기기가 죽으면 하트비트가 끊겨도 판다는 **5초간** VW 안전모드(릴레이 열림)를 유지
   (`HEARTBEAT_IGNITION_CNT_ON=5`). 이 5초간 순정 HCA_03/ACC_18은 차단된 채 대체
   송신자(openpilot)는 죽어 있음 → 차가 ADAS 메시지 소실을 봄 → 경고등.
2. 5초 후 판다 SILENT 전환 → 릴레이 닫힘 → 순정 스트림 복구 → 경고등은 사라짐.
3. 그러나 모터 ECU는 이미 `TSK_Status=7(perm_fault)`로 래치 — DBC 정의상 시동
   재점화까지 유지되는 VW 펌웨어 동작. CAN으로 못 푼다.

메시지 공백 자체를 없앨 수 없고(대체 송신자가 곧 죽은 주체), 래치는 차량 펌웨어라
불가. UDS DTC 클리어는 주행 중 위험 + 미검증이라 제외. **실효 대책은 주행 중
재부팅의 원인(발열/전압/크래시)을 없애는 것뿐.** 재부팅 발생 시 그 날짜 로그로 원인 분석.

### 시동~부팅 사이 경고등 — 설계상은 이미 원하는 동작, 실측 필요

부팅 중 판다는 SILENT(릴레이 패스스루 = 순정 직결)라 순정 기능이 되는 게 정상이고,
부팅 완료 즉시 openpilot 인수도 이미 그렇게 되어 있다. 실제로 "아예 사용 불가"라면
코드와 모순 — 확인할 것: ① 부팅 중 순정 ACC 버튼이 실제로 걸리는지, ② 경고등이
뜨고/사라지는 정확한 타이밍, ③ 부팅 직후 rlog 첫 30초의 TSK/EPS 상태.
경고등"만"의 문제면 차량 자가점검 표시라 제거 불가. 부팅 시간 단축이 체감 개선책.
참고: 이 차는 P단에서 ADAS 회로 전원이 끊겨(하드웨어) 매 시동이 콜드부팅이다.

### PSD (순정 지도 데이터) — 사망 확정

메시지는 나오지만 전 프레임 빈 껍데기 (세그먼트 ID 0). 순정 내비 없는 차량은 지도를
싣지 않는다. → 오르막/내리막 계기판 아이콘(14/15) 자동 표시는 영구 보류.

### 계기판 아이콘 + 앞차 하이라이트 공존 — 불가 확정

`Lead_Brightness` 단일 필드가 유일한 통로. 현재 배선은 "속도의 지배자에게 색을 준다"
원칙 (docs/id4_cluster_tmap.md 참고).

## 보류 중 (조건이 갖춰지면 재개)

### 카메라 하네스 롱컨 (DISABLE_RADAR 모드)

현재 카메라 하네스는 조향만 된다 (롱컨/계기판/레이더 없음). if2에는 레이더를 진단
세션에 가둬(0x700 Tester Present) openpilot이 AEB/HUD 대체 메시지를 보내는
DISABLE_RADAR 모드가 있다 — 카메라 하네스 롱컨이 가능해지지만 **AEB/FCW/EA를 잃는다.**
포팅은 가능하나 미검증. 카메라 하네스 테스터가 나타나면 재개.

### 후측방 레이더 리버싱 → 차선변경 게이트 → 추월 제안

docs/id4_side_assist_rev.md 참고. 깨끗한 추월 rlog 대기.

### 끼어들기(cut-in) — 업스트림 고정 튜닝 전환 감시

2026-07 업스트림이 `RadarLatFactor` 민감도 노브를 삭제하고 고정 50 + 강화 필터
(차선 진입속도 게이트, 요레이트 보상)로 전환했다 (de874f96, d677e0de). MEB는
`RadarLatFactor>0`이 순수 on/off 스위치가 됐다. 과거 실차에서 "민감도 30 초과 시
옆차를 앞차로 오인" 사례가 있었는데 그건 새 필터 이전 관측 — **고정 50 + 새 필터로
재발하는지 실차 확인 중.** 재발하면 MEB 한정 민감도 노브 복원 (튜닝 재계산은 값
변경 시에만 해서 업스트림 캐시 취지 유지).

MEB 끼어들기의 특수성: 코너레이더가 없어 전방 레이더 트랙으로 판정하며, 횡속도
(yvRel)는 yRel 미분+저역필터로 생성한다 (`radar_interface.py`) — HKG 코너레이더보다
노이즈가 많아 필터 여유가 덜하다. 승격 리드는 aLeadK를 [-1.5, 1.0]으로 클램프해
오탐이어도 완만한 감속만 나온다 (`radard.py _meb_apply_cutin_lead`).

## 백로그 (설계됐고 착수 전)

- **TA 버튼 커스텀 매핑** — 핸들의 놀고 있는 트래블어시스트 버튼을 carrot 토글로 (신호 파악됨)
- **빗물센서 연동** — `RLS_01` 강우량(`RS_Regenmenge` 0~100%)·와이퍼 속도로 차간거리
  +1단 / 커브 감속 강화. 실차에서 메시지 2Hz 생존 확인 (맑은 날이라 값은 0)
- **순정 AEB 발동 감지** — `AWV_03`의 `FCW_Active`/`Pre_Brake_Fill` 읽어 openpilot
  가속 억제 + 로그. 신호 위치 실차 확인 완료 (발동 사례는 아직 없음)
- **comma 화면 후측방 트랙 시각화** — 후측방 리버싱 완료 후
- 계기판 이벤트 1, 2번 정체 규명 (스캔 미완)

## 백로그 추가 (2026-07 로그 정밀 분석에서 발굴)

- **조도센서 화면 밝기 연동 — 제거함 (부작용으로 철회, 2026-07)**. `RLS_01`
  전방 조도를 carcontroller가 1Hz로 `MebAmbientLux` param에 동기(`put`) 저장했는데,
  이 디스크 쓰기가 `card` 프로세스에서 간헐적 fsync 지연(~140ms)을 유발. 정차 순간
  이 지연이 겹치면 `commIssue`→softDisable로 openpilot이 해제되고, 정차 상태에서
  ACC를 놓친 차가 **자동으로 P 기어를 물리는** 문제가 실차 rlog(4d2ba341)에서 관측됨.
  기능 효용 대비 위험이 커서 전체 제거. 재도입하려면 `put_nonblocking` 또는 param이
  아닌 cereal 메시지 경유로만.
- **계기판 스캔(ClusterTest) — 테스트 브랜치에서 제거함 (2026-07)**. 계기판 신호
  리버싱은 완료 판정(`id4_cluster_tmap.md`). 스캔용 오버라이드 스캐폴딩은 테스트
  탭에서 걷어내고, 테스트 탭은 DISABLE_RADAR 토글만 남김.
- **라이트 플래시 레버 = 커스텀 버튼** — `SMLS_01`(스토크 신호)에 `BH_Lichthupe`
  (플래시), `WH_Tipwischen`(와이퍼 팁) 비트 존재. 깜빡이 비트는 실차 로그에서 동작
  확인. 플래시 레버를 carrot 기능 토글(예: 속도모드 전환)로 매핑 가능 — 실차에서
  플래시 조작이 든 rlog로 비트 동작만 확인하면 됨
- **모터 파워/회생 표시** — `EM1_01`(40Hz, 32B) 리버싱 착수분: byte17 LE16 =
  차속(vEgo 상관 +1.000, 값=vEgo×1411), byte8 LE16 = 토크/전류 후보(aEgo 상관
  +0.735). 마저 풀면 실시간 파워/회생 게이지 가능
- **순정 카메라 물체 리스트 리버싱 (우선순위 상향)** — `MEB_Camera_01/02`(0x183/0x234, 64B)에
  8B 그룹(끝바이트 0x11 마커) 형태의 밀집 데이터. 풀면 순정 비전과 이중화
- **RCTA(후방 교차 경고) 리버싱** — 0x2B7 8Hz 생존, CRC/카운터만 해독된 상태
- **주차 초음파** — `Parkhilfe_01`/`Parken_01`은 주행 중 빈 데이터. 주차 장면
  rlog로 거리값 존재 여부 판정 필요
